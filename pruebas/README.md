# Pruebas de OneBook

Pruebas automáticas con Playwright. Cada archivo cubre un hito y comprueba que todo funcione: en celular y escritorio, con texto del 90% al 150%, con las tres fuentes, en claro, oscuro y alto contraste, y con el teclado. Fallan si encuentran desbordes, errores, texto con poco contraste o un comportamiento distinto del esperado.

Las pruebas sirven el sitio en `http://127.0.0.1:<puerto>/OneLearn/`, igual que GitHub Pages, con un servidor incluido en `lib.js`. No hace falta instalar nada más.

## Cómo correrlas

En tu computadora, la primera vez:

```
cd pruebas
npm install
npx playwright install chromium
```

Después:

```
npm test               # todas
node todas.js 3 24     # solo la 3 y la 24
DETALLE=1 node 2-lectura.js   # muestra también cada comprobación que pasa
```

Por omisión, `pagina()` abre un navegador con un espacio de negocio ya creado (el módulo de negocio encendido; al cargar, `empresa.js` le crea su empresa automática con quien lo usa como propietario); `perfil:false` lo deja sin espacio y un objeto pone ese perfil.
